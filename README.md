# Бон и Дзогчен — справочник

Приложение (PWA) со справочником по книгам Тензина Вангьяла Ринпоче: термины, практики, ключевые идеи и короткие цитаты со ссылкой на книгу и главу. Работает на телефоне и компьютере, ставится на главный экран и открывается без интернета.

Книги, по которым составлен справочник:
- «Чудеса естественного ума»
- «Тибетская йога сна и сновидений»
- «Пробуждение священного тела» (тибетская йога дыхания и движения)
- «Исцеление формой, энергией и светом»
- «Тибетская йога тела, речи и ума»

В разделе «Практикум»: таймер медитации, вечерняя практика сна по шагам, дневник снов и практики, карточки для запоминания терминов, схемы и таблицы, заметки к статьям. Записи хранятся только на устройстве.

Тибетские слоги нарисованы шрифтом Noto Serif Tibetan (лицензия SIL Open Font License, см. `fonts/OFL.txt`).

Тексты книг в репозиторий не входят: справочник содержит только пересказ и короткие цитаты.

## Как обновить данные

Данные лежат в `data/all.json`. Они собираются из отдельных файлов по книгам:

```
python3 scripts/build.py ПАПКА_С_JSON [ПАПКА_С_КНИГАМИ_TXT]
```

Если указать папку с книгами, скрипт проверит, что каждая цитата дословно есть в книге. После изменения данных увеличьте `VERSION` в `sw.js`, чтобы телефоны получили обновление.
